## Implementation Tasks

### 1. Category Class Implementation

#### 1.1 Class Initialization
- Create `Category` class with `__init__(self, name)` method
- Initialize `self.name` to store category name
- Initialize `self.ledger` as empty list to store transactions

#### 1.2 Deposit Method
- Method signature: `deposit(self, amount, description="")`
- Append dictionary to ledger: `{'amount': amount, 'description': description}`
- Default description to empty string if not provided

#### 1.3 Withdraw Method
- Method signature: `withdraw(self, amount, description="")`
- Check if sufficient funds using `check_funds(amount)`
- If funds available:
  - Append `{'amount': -amount, 'description': description}` to ledger
  - Return `True`
- If insufficient funds, return `False`
- Default description to empty string

#### 1.4 Get Balance Method
- Method signature: `get_balance(self)`
- Sum all `amount` values in ledger
- Return total balance

#### 1.5 Transfer Method
- Method signature: `transfer(self, amount, category)`
- Check if sufficient funds using `check_funds(amount)`
- If funds available:
  - Withdraw from current category with description `f"Transfer to {category.name}"`
  - Deposit to target category with description `f"Transfer from {self.name}"`
  - Return `True`
- If insufficient funds, return `False`

#### 1.6 Check Funds Method
- Method signature: `check_funds(self, amount)`
- Return `True` if `amount <= get_balance()`
- Return `False` otherwise

#### 1.7 String Representation (__str__ method)
- Create 30-character title line with category name centered between `*` characters
- For each ledger entry:
  - Format description: left-aligned, max 23 characters
  - Format amount: right-aligned, 7 characters, 2 decimal places
  - Total line width: 30 characters
- Add final line: `Total: {balance}` with 2 decimal places
- Join all lines with newline characters

**Formatting details:**
- Title: `name.center(30, '*')`
- Each entry: `f"{description[:23]:23}{amount:>7.2f}"`
- Total line: `f"Total: {balance:.2f}"`

### 2. Create Spend Chart Function

#### 2.1 Function Signature
- `create_spend_chart(categories)` - accepts list of Category instances

#### 2.2 Calculate Spending Percentages
- For each category, sum all negative amounts (withdrawals only)
- Calculate total spent across all categories
- Calculate percentage for each: `(category_spent / total_spent) * 100`
- Round down to nearest 10: `(percentage // 10) * 10`

#### 2.3 Build Chart String
- Start with title: `"Percentage spent by category"`
- Build y-axis labels from 100 to 0 in steps of 10
- For each percentage level (100, 90, 80, ..., 0):
  - Format: `f"{level:>3}|"` (right-aligned, 3 chars)
  - Add space, then for each category:
    - Add `"o"` if category percentage >= level, else space
    - Add two spaces between categories
  - Add two trailing spaces after last category
- Add horizontal line: `"    " + "-" * (3 * len(categories) + 1)`
- Add category names vertically:
  - Find max name length
  - For each character position (0 to max_length - 1):
    - Start with 5 spaces
    - For each category, add character at position or space if name too short
    - Add two spaces between categories
    - Add two trailing spaces after last category

**Spacing rules:**
- Between bars: 2 spaces
- After last bar: 2 spaces
- Horizontal line: starts at column 4, extends 2 chars past last bar
- Category names: start at column 5, 2 spaces between, 2 spaces after last

#### 2.4 Return Chart
- Join all lines with `\n`
- Do NOT add trailing newline at end

## Implementation Notes

### Key Requirements
1. All amounts stored as positive/negative numbers in ledger
2. Withdrawals store negative amounts
3. Balance calculated by summing all ledger amounts
4. Transfer creates two ledger entries (one withdrawal, one deposit)
5. String representation must match exact spacing (30 chars per line)
6. Chart percentages round DOWN to nearest 10
7. Chart uses only withdrawals for percentage calculation
8. No trailing newline in chart output

### Edge Cases to Handle
- Empty descriptions default to ""
- Insufficient funds return False for withdraw/transfer
- Category names longer than 23 chars truncate in ledger display
- Category names of varying lengths in chart (pad with spaces)
- Zero or negative deposits/withdrawals (allow as specified)
