## Implementation Tasks

### 1. Implement `get_q_value(self, state, action)`
**Purpose**: Retrieve Q-value for a (state, action) pair from the Q-table

**Requirements**:
- Convert state list to tuple for dictionary key lookup
- Return Q-value from `self.q` dictionary
- Return 0 if no Q-value exists for the pair

**Implementation approach**:
```python
def get_q_value(self, state, action):
    return self.q.get((tuple(state), action), 0)
```

**Key considerations**:
- States are passed as lists but must be tuples for dict keys
- Use `.get()` with default value 0 for non-existent entries

---

### 2. Implement `update_q_value(self, state, action, old_q, reward, future_rewards)`
**Purpose**: Update Q-value using the Q-learning formula

**Requirements**:
- Apply formula: Q(s,a) ← old_q + alpha × (new_estimate - old_q)
- new_estimate = reward + future_rewards
- Store updated value in `self.q` dictionary

**Implementation approach**:
```python
def update_q_value(self, state, action, old_q, reward, future_rewards):
    new_estimate = reward + future_rewards
    self.q[(tuple(state), action)] = old_q + self.alpha * (new_estimate - old_q)
```

**Key considerations**:
- `self.alpha` is the learning rate (how much to weight new information)
- Convert state to tuple before storing in dictionary
- Formula combines immediate reward with estimated future rewards

---

### 3. Implement `best_future_reward(self, state)`
**Purpose**: Find maximum Q-value among all available actions in a state

**Requirements**:
- Get all available actions using `Nim.available_actions(state)`
- Find maximum Q-value across all actions
- Return 0 if no actions available (terminal state)
- Assume Q-value of 0 for unknown (state, action) pairs

**Implementation approach**:
```python
def best_future_reward(self, state):
    actions = Nim.available_actions(state)
    if not actions:
        return 0
    return max(self.get_q_value(state, action) for action in actions)
```

**Key considerations**:
- Use `Nim.available_actions()` class method to get valid actions
- Empty action set means game is over (all piles empty)
- Leverage `get_q_value()` which already handles missing entries

---

### 4. Implement `choose_action(self, state, epsilon=True)`
**Purpose**: Select action using epsilon-greedy strategy

**Requirements**:
- If `epsilon=False`: return action with highest Q-value (greedy)
- If `epsilon=True`: 
  - With probability `self.epsilon`: choose random action (exploration)
  - Otherwise: choose best action (exploitation)
- Handle ties in Q-values (any tied action is acceptable)

**Implementation approach**:
```python
def choose_action(self, state, epsilon=True):
    actions = Nim.available_actions(state)
    
    if epsilon and random.random() < self.epsilon:
        return random.choice(list(actions))
    
    best_actions = []
    best_value = float('-inf')
    
    for action in actions:
        q_value = self.get_q_value(state, action)
        if q_value > best_value:
            best_value = q_value
            best_actions = [action]
        elif q_value == best_value:
            best_actions.append(action)
    
    return random.choice(best_actions)
```

**Key considerations**:
- Epsilon-greedy balances exploration vs exploitation
- `random.random()` generates float in [0.0, 1.0)
- Track all actions with best Q-value to handle ties
- Random selection among tied actions prevents bias

## Implementation Notes

### Minimal Code Philosophy
- Each method should be concise and direct
- No unnecessary abstractions or helper functions
- Leverage existing methods where possible (e.g., `get_q_value()` in `best_future_reward()`)

### Data Structure Considerations
- **State representation**: Lists in function parameters, tuples in dictionary keys
- **Q-table**: Dictionary mapping `(tuple(state), action)` → float
- **Actions**: Set of `(pile_index, count)` tuples

### Edge Cases
- Empty piles (terminal state): `best_future_reward()` returns 0
- Unknown Q-values: default to 0
- Tied Q-values: random selection is acceptable
- First moves: all Q-values are 0, so random selection occurs
