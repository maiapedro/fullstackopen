# Tower of Hanoi Implementation Plan

## Overview
Implement a `hanoi_solver` function that solves the Tower of Hanoi puzzle and returns a string representation of all moves from start to finish.

## Requirements Analysis

### Function Specification
- **Name**: `hanoi_solver`
- **Parameter**: Single integer `n` (number of disks)
- **Return**: String with all puzzle states, one per line
- **Moves**: Must solve in exactly 2^n - 1 moves

### Output Format
- Three rods represented as lists: `[rod1] [rod2] [rod3]`
- Disks represented by integers (1 = smallest)
- Each state on a new line (separated by `\n`)
- Initial state: all disks on first rod in descending order `[n, n-1, ..., 2, 1]`
- Final state: all disks on third rod `[] [] [n, n-1, ..., 2, 1]`

### Rules
1. Move only top-most disk
2. Move only one disk at a time
3. Cannot place larger disk on smaller disk

## Implementation Strategy

### Algorithm: Recursive Approach
The Tower of Hanoi has an elegant recursive solution:

**Base case**: If n=1, move disk from source to destination

**Recursive case** (n > 1):
1. Move n-1 disks from source to auxiliary (using destination as temporary)
2. Move largest disk from source to destination
3. Move n-1 disks from auxiliary to destination (using source as temporary)

### Data Structure
- Use three lists to represent the three rods
- Track state after each move
- Build output string incrementally

### Implementation Steps

1. **Initialize state**
   - Create three rods: `[n, n-1, ..., 1]`, `[]`, `[]`
   - Add initial state to output

2. **Implement recursive helper function**
   - Parameters: number of disks, source rod, destination rod, auxiliary rod
   - Perform recursive moves as described above
   - After each disk move, capture current state and append to output

3. **Format output**
   - Convert rod lists to string format
   - Join all states with newline characters

4. **Return result**
   - Return complete string with all states
