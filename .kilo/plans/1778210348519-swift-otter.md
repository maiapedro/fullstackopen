# Crossword Puzzle CSP Solver Implementation Plan

## Overview
Implement a constraint satisfaction problem (CSP) solver for crossword puzzles using backtracking search with arc consistency (AC-3 algorithm). The solver must handle unary constraints (word length) and binary constraints (character overlaps between intersecting words).

## Current State
- `crossword.py`: Fully implemented with `Variable` and `Crossword` classes
- `generate.py`: Has 8 functions that need implementation:
  1. `enforce_node_consistency()`
  2. `revise(x, y)`
  3. `ac3(arcs=None)`
  4. `assignment_complete(assignment)`
  5. `consistent(assignment)`
  6. `order_domain_values(var, assignment)`
  7. `select_unassigned_variable(assignment)`
  8. `backtrack(assignment)`

## Implementation Strategy

### Phase 1: Basic Constraint Enforcement

#### 1.1 enforce_node_consistency()
**Purpose**: Remove values from domains that don't match variable length (unary constraint)

**Implementation**:
- Iterate through all variables in `self.domains`
- For each variable, remove words that don't match `variable.length`
- Use `self.domains[var].remove(word)` or create new set with matching words
- No return value needed

**Key Logic**:
```
for each variable in self.domains:
    remove words where len(word) != variable.length
```

---

#### 1.2 revise(x, y)
**Purpose**: Make variable x arc-consistent with variable y

**Implementation**:
- Get overlap between x and y using `self.crossword.overlaps[x, y]`
- If no overlap, return False
- Extract overlap indices (i, j) where x[i] must equal y[j]
- Check each value in x's domain against all values in y's domain
- Remove x values that have no compatible y value
- Return True if any revision made, False otherwise

**Key Logic**:
```
overlap = self.crossword.overlaps[x, y]
if overlap is None:
    return False
    
i, j = overlap
revised = False
for x_word in self.domains[x].copy():
    if no y_word in self.domains[y] where x_word[i] == y_word[j]:
        self.domains[x].remove(x_word)
        revised = True
return revised
```

---

### Phase 2: Arc Consistency Algorithm

#### 2.1 ac3(arcs=None)
**Purpose**: Enforce arc consistency across all variables using AC-3 algorithm

**Implementation**:
- Initialize queue with all arcs if `arcs` is None, otherwise use provided arcs
- All arcs means: for each variable, create arc (var, neighbor) for all neighbors
- Process queue using while loop
- For each arc (x, y), call `revise(x, y)`
- If revised and x's domain becomes empty, return False (no solution)
- If revised, add all arcs (neighbor, x) back to queue for x's neighbors (except y)
- Return True when queue is empty

**Key Logic**:
```
if arcs is None:
    queue = [(v1, v2) for v1 in variables for v2 in neighbors(v1)]
else:
    queue = arcs.copy()

while queue not empty:
    (x, y) = dequeue()
    if revise(x, y):
        if domain[x] is empty:
            return False
        for neighbor in neighbors(x) - {y}:
            enqueue((neighbor, x))
return True
```

### Phase 3: Assignment Validation

#### 3.1 assignment_complete(assignment)
**Purpose**: Check if all variables have been assigned

**Implementation**:
- Compare number of assigned variables to total variables
- Return True if `len(assignment) == len(self.crossword.variables)`
- Alternative: check if all variables in `self.crossword.variables` are keys in assignment

**Key Logic**:
```
return len(assignment) == len(self.crossword.variables)
```

---

#### 3.2 consistent(assignment)
**Purpose**: Verify assignment satisfies all constraints

**Implementation**:
Check three constraints:
1. **Uniqueness**: All assigned words are distinct
2. **Length**: Each word matches its variable's length
3. **No conflicts**: Overlapping variables have matching characters at overlap positions

**Key Logic**:
```
# Check uniqueness
if len(values) != len(set(values)):
    return False

# Check length constraint
for var, word in assignment:
    if len(word) != var.length:
        return False

# Check overlap constraints
for var1 in assignment:
    for var2 in neighbors(var1):
        if var2 in assignment:
            overlap = self.crossword.overlaps[var1, var2]
            if overlap:
                i, j = overlap
                if assignment[var1][i] != assignment[var2][j]:
                    return False
return True
```

### Phase 4: Heuristics (Can implement basic version first, then optimize)

#### 4.1 order_domain_values(var, assignment)
**Purpose**: Order domain values by least-constraining values heuristic

**Basic Implementation** (Phase 4a):
- Return list of domain values in any order
- `return list(self.domains[var])`

**Optimized Implementation** (Phase 4b):
- For each value in var's domain, count how many neighbor values it eliminates
- Only consider unassigned neighbors
- For each neighbor, count values that would conflict with this choice
- Sort by ascending elimination count

**Key Logic**:
```
def count_eliminations(value):
    count = 0
    for neighbor in unassigned_neighbors:
        overlap = self.crossword.overlaps[var, neighbor]
        if overlap:
            i, j = overlap
            for neighbor_value in self.domains[neighbor]:
                if value[i] != neighbor_value[j]:
                    count += 1
    return count

return sorted(self.domains[var], key=count_eliminations)
```

---

#### 4.2 select_unassigned_variable(assignment)
**Purpose**: Choose next variable using MRV and degree heuristics

**Basic Implementation** (Phase 4a):
- Return any unassigned variable
- `return next(v for v in self.crossword.variables if v not in assignment)`

**Optimized Implementation** (Phase 4b):
- Primary: Minimum Remaining Values (MRV) - choose variable with fewest domain values
- Tiebreaker: Degree heuristic - choose variable with most unassigned neighbors
- Sort by (domain_size, -neighbor_count)

**Key Logic**:
```
unassigned = [v for v in self.crossword.variables if v not in assignment]

def sort_key(var):
    domain_size = len(self.domains[var])
    degree = len([n for n in self.crossword.neighbors(var) if n not in assignment])
    return (domain_size, -degree)

return min(unassigned, key=sort_key)
```

### Phase 5: Backtracking Search

#### 5.1 backtrack(assignment)
**Purpose**: Recursive backtracking search to find complete assignment

**Implementation**:
- Base case: if assignment complete, return it
- Select unassigned variable using heuristic
- Try each value in ordered domain
- Check if assignment + value is consistent
- Recursively backtrack with new assignment
- If recursive call succeeds, return result
- If all values fail, return None (backtrack)

**Optional Enhancement**: Maintain arc consistency after each assignment by calling `ac3()` with arcs from assigned variable to neighbors

**Key Logic**:
```
if assignment_complete(assignment):
    return assignment

var = select_unassigned_variable(assignment)

for value in order_domain_values(var, assignment):
    assignment[var] = value
    if consistent(assignment):
        result = backtrack(assignment)
        if result is not None:
            return result
    del assignment[var]

return None
```

## Key Data Structures

- `self.domains`: `dict[Variable, set[str]]` - Maps variables to possible words
- `self.crossword.overlaps`: `dict[(Variable, Variable), tuple[int, int] | None]` - Overlap positions
- `self.crossword.neighbors(var)`: Returns set of overlapping variables
- `assignment`: `dict[Variable, str]` - Maps variables to assigned words

---

## Edge Cases to Handle

1. **Empty domains**: ac3 should return False if any domain becomes empty
2. **No overlaps**: revise should return False immediately
3. **No solution**: backtrack should return None
4. **Single variable**: Should work with minimal crosswords
5. **All same length words**: Uniqueness constraint must still apply

---

## Complexity Notes

- **AC-3**: O(ed³) where e = arcs, d = domain size
- **Backtracking**: Worst case O(d^n) where n = variables
- **Heuristics reduce search space significantly**
- MRV and least-constraining-value are most impactful optimizations
