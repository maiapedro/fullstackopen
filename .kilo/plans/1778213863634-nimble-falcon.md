## Implementation Tasks

### Task 1: Implement `preprocess()` Function
**File:** `parser.py:58-65`

**Requirements:**
- Accept sentence string as input
- Use `nltk.word_tokenize()` to tokenize
- Convert all words to lowercase
- Filter out words without at least one alphabetic character
- Return list of lowercased words

**Implementation:**
```python
def preprocess(sentence):
    tokens = nltk.word_tokenize(sentence)
    return [word.lower() for word in tokens if any(c.isalpha() for c in word)]
```

### Task 2: Define Context-Free Grammar Rules in NONTERMINALS
**File:** `parser.py:17-19`

**Grammar Rules Needed:**

Based on sentence analysis, we need rules for:
- Sentence structures (simple, compound)
- Noun phrases (with determiners, adjectives)
- Verb phrases (with objects, prepositional phrases)
- Prepositional phrases
- Conjunctions connecting clauses

**Minimal Rule Set:**
```
S -> NP VP | S Conj S
NP -> N | Det N | Det AP N | NP PP
AP -> Adj | Adj AP
VP -> V | V NP | V PP | V NP PP | V Adv | V Adv Conj VP | VP Conj VP
PP -> P NP
```

**Explanation:**
- `S -> NP VP` - Basic sentence structure
- `S -> S Conj S` - Compound sentences with "and", "until"
- `NP -> N` - Simple noun phrase (pronouns)
- `NP -> Det N` - Determiner + noun
- `NP -> Det AP N` - Determiner + adjectives + noun
- `NP -> NP PP` - Noun phrase with prepositional phrase modifier
- `AP -> Adj | Adj AP` - One or more adjectives
- `VP -> V` - Intransitive verb
- `VP -> V NP` - Transitive verb with object
- `VP -> V PP` - Verb with prepositional phrase
- `VP -> V NP PP` - Verb with object and prepositional phrase
- `VP -> V Adv` - Verb with adverb
- `VP -> V Adv Conj VP` - Handles "sat down and lit"
- `VP -> VP Conj VP` - Compound verb phrases
- `PP -> P NP` - Prepositional phrase

### Task 3: Implement `np_chunk()` Function
**File:** `parser.py:68-75`

**Requirements:**
- Accept `nltk.tree` object with label "S"
- Return list of `nltk.tree` objects with label "NP"
- Only return NP subtrees that don't contain other NPs (leaf noun phrases)

**Algorithm:**
1. Recursively traverse the tree
2. When finding an NP node, check if it contains other NPs
3. If no nested NPs, add to result list
4. If it has nested NPs, recurse into children but don't add parent

**Implementation:**
```python
def np_chunk(tree):
    chunks = []
    for subtree in tree.subtrees():
        if subtree.label() == "NP":
            # Check if this NP contains other NPs
            has_nested_np = any(
                child.label() == "NP" 
                for child in subtree.subtrees() 
                if child != subtree
            )
            if not has_nested_np:
                chunks.append(subtree)
    return chunks
```

## Edge Cases & Considerations

- **Over-generation:** Grammar should not accept "Armchair on the sat Holmes"
- **Under-generation:** Should handle multiple adjectives without hardcoding count
- **Ambiguity:** Multiple parse trees are acceptable for ambiguous sentences
- **Determiners:** Avoid "the the armchair" by proper NP structure
- **Nested NPs:** "the armchair in the home" contains "the home" - only extract innermost

## Success Criteria

- All 10 test sentences parse successfully
- `preprocess()` correctly tokenizes and filters words
- `np_chunk()` extracts only leaf noun phrases
- Grammar is general enough to handle variations but not over-generate
- No modifications to TERMINALS or other parts of parser.py
