# Rectangle and Square OOP Implementation Plan

## Overview
Implement a Rectangle class and a Square subclass using object-oriented programming principles. The Square class will inherit from Rectangle and override specific methods to maintain square properties.

## Project Structure
- **File to create**: `shape_calculator.py` (main implementation file)
- **Test file**: Will need to verify if tests exist or need to be created

## Implementation Details

### 1. Rectangle Class

**Attributes:**
- `width`: Width of the rectangle
- `height`: Height of the rectangle

**Methods:**

1. `__init__(self, width, height)` - Initialize with width and height
2. `set_width(self, width)` - Set the width
3. `set_height(self, height)` - Set the height
4. `get_area(self)` - Return width × height
5. `get_perimeter(self)` - Return 2 × (width + height)
6. `get_diagonal(self)` - Return √(width² + height²) using `math.sqrt()`
7. `get_picture(self)` - Return string representation using `*` characters
   - Each line has `width` asterisks
   - Total of `height` lines
   - Each line ends with `\n`
   - Return "Too big for picture." if width or height > 50
8. `get_amount_inside(self, shape)` - Calculate how many times the passed shape fits inside
   - Use integer division: `(self.width // shape.width) * (self.height // shape.height)`
9. `__str__(self)` - Return "Rectangle(width={width}, height={height})"

### 2. Square Class (subclass of Rectangle)

**Inheritance:**
- Inherits from Rectangle class

**Methods to implement/override:**

1. `__init__(self, side)` - Initialize with single side length
   - Call parent `__init__` with side for both width and height
2. `set_width(self, side)` - Override to set both width and height
3. `set_height(self, side)` - Override to set both width and height
4. `set_side(self, side)` - New method to set both dimensions
5. `__str__(self)` - Return "Square(side={side})"

**Inherited methods (no override needed):**
- `get_area()`
- `get_perimeter()`
- `get_diagonal()`
- `get_picture()`
- `get_amount_inside()`

## Implementation Steps

1. Create `shape_calculator.py` file
2. Import required modules (`math` for sqrt)
3. Implement Rectangle class with all methods
4. Implement Square class as subclass
5. Test with provided usage example
6. Verify all 22 test cases pass

## Key Design Considerations

- **Square maintains square property**: When `set_width()` or `set_height()` is called on a Square, both dimensions must be updated
- **Minimal code**: Use parent class methods where possible, only override what's necessary
- **String representation**: Use `__str__` magic method for proper string representation
- **Math operations**: Import `math.sqrt()` for diagonal calculation
- **Edge cases**: Handle "Too big for picture" case in `get_picture()`
