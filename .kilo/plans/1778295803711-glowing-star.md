## Requirements Analysis

### Rectangle Class
- **Attributes**: `width`, `height`
- **Methods**:
  - `set_width(width)` - Update width
  - `set_height(height)` - Update height
  - `get_area()` - Return width × height
  - `get_perimeter()` - Return 2(width + height)
  - `get_diagonal()` - Return √(width² + height²)
  - `get_picture()` - Return ASCII art or "Too big for picture." if dimension > 50
  - `get_amount_inside(shape)` - Calculate how many times shape fits inside
  - `__str__()` - Return "Rectangle(width=W, height=H)"
