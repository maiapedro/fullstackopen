# Traffic Sign Classification Implementation Plan

## Project Overview
Implement a neural network using TensorFlow to classify German traffic signs from the GTSRB dataset. The project requires implementing two main functions: `load_data()` and `get_model()`.

## Current State Analysis
- **File**: `traffic.py` (74 lines)
- **Dataset**: GTSRB with 43 categories (directories 0-42)
- **Image format**: PPM files
- **Dependencies**: opencv-python, scikit-learn, tensorflow
- **Global constants**: 
  - IMG_WIDTH = 30, IMG_HEIGHT = 30
  - NUM_CATEGORIES = 43
  - EPOCHS = 10, TEST_SIZE = 0.4

## Implementation Tasks

### Task 1: Implement `load_data()` function
**Location**: traffic.py:47-61

**Requirements**:
- Accept `data_dir` parameter (path to dataset)
- Return tuple `(images, labels)`
- Images: list of numpy.ndarray with shape (30, 30, 3)
- Labels: list of integers (0-42)
- Platform-independent path handling using `os.sep` and `os.path.join`

**Implementation approach**:
1. Initialize empty lists for images and labels
2. Loop through categories 0 to NUM_CATEGORIES-1
3. For each category directory:
   - Construct path using `os.path.join(data_dir, str(category))`
   - List all files in the directory
   - For each image file:
     - Read using `cv2.imread()`
     - Resize to (IMG_WIDTH, IMG_HEIGHT) using `cv2.resize()`
     - Append to images list
     - Append category number to labels list
4. Return (images, labels)

**Key functions to use**:
- `os.listdir()` - list files in directory
- `os.path.join()` - construct paths
- `cv2.imread()` - read image as numpy array
- `cv2.resize()` - resize image to target dimensions

### Task 2: Implement `get_model()` function
**Location**: traffic.py:64-70

**Requirements**:
- Return compiled CNN model
- Input shape: (IMG_WIDTH, IMG_HEIGHT, 3) = (30, 30, 3)
- Output layer: NUM_CATEGORIES units (43) with softmax activation
- Model must be compiled with optimizer, loss function, and metrics

**Initial architecture approach**:
Start with a baseline CNN architecture, then experiment:

**Baseline model**:
1. Conv2D layer (32 filters, 3x3 kernel, ReLU activation)
2. MaxPooling2D (2x2 pool size)
3. Conv2D layer (64 filters, 3x3 kernel, ReLU activation)
4. MaxPooling2D (2x2 pool size)
5. Flatten layer
6. Dense layer (128 units, ReLU activation)
7. Output Dense layer (43 units, softmax activation)

**Compilation**:
- Optimizer: Adam
- Loss: categorical_crossentropy
- Metrics: accuracy

**Key TensorFlow/Keras components**:
- `tf.keras.models.Sequential()`
- `tf.keras.layers.Conv2D()`
- `tf.keras.layers.MaxPooling2D()`
- `tf.keras.layers.Flatten()`
- `tf.keras.layers.Dense()`
- `tf.keras.layers.Dropout()` (for experimentation)
- `model.compile()`
