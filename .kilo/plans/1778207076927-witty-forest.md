# Knights and Knaves Puzzle Solution Plan

## Overview
Implement propositional logic knowledge bases to solve 4 Knights and Knaves puzzles using the existing model-checking algorithm in `logic.py`.

## Problem Understanding

### Core Rules
- Each character is either a knight OR a knave (mutually exclusive)
- Knights always tell the truth (statement is true)
- Knaves always lie (statement is false)

### Key Insight
When a character makes a statement:
- If they're a knight → the statement must be true
- If they're a knave → the statement must be false
- This can be expressed as: `Biconditional(CharacterIsKnight, Statement)`

## Implementation Strategy

### General Knowledge Structure
Each knowledge base needs two types of information:

1. **Structural constraints** (applies to all puzzles):
   - Each character is either a knight OR a knave: `Or(XKnight, XKnave)`
   - Each character cannot be both: `Not(And(XKnight, XKnave))`
   - Alternative: `Biconditional(XKnight, Not(XKnave))`

2. **Statement encoding**:
   - For each statement made, encode: `Biconditional(SpeakerIsKnight, StatementContent)`

### Puzzle 0: A says "I am both a knight and a knave"
**Characters**: A

**Knowledge to encode**:
- A is either knight or knave (not both)
- A's statement: "I am both a knight and a knave" = `And(AKnight, AKnave)`
- If A is knight, statement is true; if knave, statement is false

**Expected result**: A is a knave (statement is impossible, so must be lying)

### Puzzle 1: A says "We are both knaves", B says nothing
**Characters**: A, B

**Knowledge to encode**:
- Both A and B are either knight or knave (not both)
- A's statement: "We are both knaves" = `And(AKnave, BKnave)`
- B makes no statement (no additional constraint beyond structural)

**Expected result**: A is knave, B is knight

### Puzzle 2: A says "We are the same kind", B says "We are of different kinds"
**Characters**: A, B

**Knowledge to encode**:
- Both A and B are either knight or knave (not both)
- A's statement: "We are the same kind" = `Or(And(AKnight, BKnight), And(AKnave, BKnave))`
- B's statement: "We are of different kinds" = `Or(And(AKnight, BKnave), And(AKnave, BKnight))`

**Expected result**: A is knight, B is knave (their statements contradict, so one must be lying)

### Puzzle 3: Complex nested statements
**Characters**: A, B, C

**Statements**:
- A says either "I am a knight" OR "I am a knave" (unknown which)
- B says "A said 'I am a knave'"
- B says "C is a knave"
- C says "A is a knight"

**Knowledge to encode**:
- All three are either knight or knave (not both)
- Key insight: A knight would never say "I am a knave" (false statement)
- A knave would never say "I am a knave" (true statement)
- Therefore, A could not have said "I am a knave"
- B's first statement "A said 'I am a knave'" must be false
- So B is a knave
- B's second statement: "C is a knave" (encode with biconditional)
- C's statement: "A is a knight" (encode with biconditional)

**Expected result**: A is knight, B is knave, C is knight

## Implementation Steps

1. **Puzzle 0** (simplest):
   - Add structural constraint for A
   - Add biconditional for A's statement

2. **Puzzle 1**:
   - Add structural constraints for A and B
   - Add biconditional for A's statement

3. **Puzzle 2**:
   - Add structural constraints for A and B
   - Add biconditionals for both A's and B's statements

4. **Puzzle 3** (most complex):
   - Add structural constraints for A, B, and C
   - Encode the logical impossibility of A saying "I am a knave"
   - Add biconditionals for B's and C's statements

## Testing
Run `python puzzle.py` after implementation to verify all puzzles produce correct output.

## Notes
- Use `Biconditional` for "if and only if" relationships
- Use `Implication` for "if...then" relationships
- Keep encodings direct and minimal - let the model checker do the reasoning
- Don't pre-solve puzzles in the knowledge base
