## Implementation Details

### 1. HashTable Class Structure
- **Attribute**: `collection` - initialized as empty dictionary `{}`
- **Purpose**: Stores key-value pairs where the key is the hash value

### 2. Hash Function
- **Method**: `hash(self, key: str) -> int`
- **Logic**: Sum Unicode values of all characters using `ord()`
- **Example**: `hash('golf')` → ord('g') + ord('o') + ord('l') + ord('f') = 103 + 111 + 108 + 102 = 424

### 3. Add Method
- **Method**: `add(self, key: str, value: any) -> None`
- **Logic**:
  1. Compute hash of the key
  2. If hash doesn't exist in collection, create nested dictionary
  3. Store key-value pair in nested dictionary at hash index
- **Collision handling**: Multiple keys with same hash stored in same nested dict
- **Example**: 
  - `add('golf', 'sport')` → `{424: {'golf': 'sport'}}`
  - `add('dear', 'friend')` and `add('read', 'book')` → `{412: {'dear': 'friend', 'read': 'book'}}`

### 4. Remove Method
- **Method**: `remove(self, key: str) -> None`
- **Logic**:
  1. Compute hash of the key
  2. Check if hash exists in collection
  3. Check if key exists in nested dictionary
  4. Remove only the specific key-value pair
  5. If nested dict becomes empty, optionally remove the hash key
- **Error handling**: No error if key doesn't exist

### 5. Lookup Method
- **Method**: `lookup(self, key: str) -> any`
- **Logic**:
  1. Compute hash of the key
  2. Check if hash exists in collection
  3. Check if key exists in nested dictionary
  4. Return value if found, else return None
- **Return**: Value associated with key, or None if not found
