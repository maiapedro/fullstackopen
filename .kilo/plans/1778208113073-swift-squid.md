# Minesweeper AI Implementation Plan

## Overview
Implement an AI agent that can play Minesweeper by using propositional logic and knowledge-based inference to identify safe cells and mines.

## Current State
- `Minesweeper` class: Fully implemented (game logic)
- `Sentence` class: Structure defined, 4 methods need implementation
- `MinesweeperAI` class: Structure defined, 3 methods need implementation

## Implementation Tasks

### 1. Sentence Class Methods

#### 1.1 `known_mines()`
**Logic**: If the count equals the number of cells, all cells are mines.
- Check if `self.count == len(self.cells)`
- Return `self.cells` if true, otherwise empty set

#### 1.2 `known_safes()`
**Logic**: If count is 0, all cells are safe.
- Check if `self.count == 0`
- Return `self.cells` if true, otherwise empty set

#### 1.3 `mark_mine(cell)`
**Logic**: Remove the cell from the sentence and decrement count.
- Check if `cell in self.cells`
- If yes: remove cell from `self.cells` and decrement `self.count`
- If no: do nothing

#### 1.4 `mark_safe(cell)`
**Logic**: Remove the cell from the sentence (count unchanged).
- Check if `cell in self.cells`
- If yes: remove cell from `self.cells`
- If no: do nothing

### 2. MinesweeperAI Class Methods

#### 2.1 `add_knowledge(cell, count)`
**Most complex method - implements the core AI logic.**

**Step 1**: Mark the cell as a move made
- Add `cell` to `self.moves_made`

**Step 2**: Mark the cell as safe
- Call `self.mark_safe(cell)`

**Step 3**: Create new sentence from neighbors
- Get all 8 neighboring cells (considering board boundaries)
- Filter out cells already known to be safe or mines
- Create `Sentence(undetermined_neighbors, count)` and add to `self.knowledge`

**Step 4**: Iteratively mark new mines/safes
- Loop through `self.knowledge`
- For each sentence, check `known_mines()` and `known_safes()`
- Mark any discovered mines/safes using `self.mark_mine()` / `self.mark_safe()`
- Repeat until no new inferences can be made

**Step 5**: Infer new sentences using subset method
- For each pair of sentences in `self.knowledge`:
  - If `sentence1.cells` is a subset of `sentence2.cells`:
    - Create new sentence: `(sentence2.cells - sentence1.cells, sentence2.count - sentence1.count)`
    - Add to knowledge if not already present
- Repeat inference process (Step 4) after adding new sentences

**Step 6**: Clean up knowledge base
- Remove empty sentences (where `len(cells) == 0`)
- Remove duplicate sentences

#### 2.2 `make_safe_move()`
**Logic**: Return a safe cell that hasn't been played yet.
- Find cells in `self.safes` that are not in `self.moves_made`
- Return any such cell, or `None` if none exist

#### 2.3 `make_random_move()`
**Logic**: Return a random valid move.
- Generate all possible cells on the board
- Filter out cells in `self.moves_made` and `self.mines`
- Return random cell from remaining options, or `None` if none exist

## Implementation Details

### Key Considerations

1. **Iterative Inference**: After any knowledge update, must check for new inferences repeatedly until no more can be made

2. **Subset Inference**: Critical for advanced reasoning
   - Example: `{A,B,C} = 1` and `{A,B,C,D,E} = 2` → infer `{D,E} = 1`

3. **Set Operations**: Use Python set operations efficiently
   - `issubset()` for checking subsets
   - `-` operator for set difference
   - Avoid modifying sets while iterating

4. **Neighbor Calculation**: For cell `(i, j)`, neighbors are:
   - Range: `i-1` to `i+1`, `j-1` to `j+1`
   - Exclude the cell itself
   - Stay within board boundaries `[0, height)` x `[0, width)`

5. **Knowledge Base Management**:
   - Remove sentences with 0 cells
   - Avoid duplicate sentences
   - Update all sentences when marking mines/safes

## Edge Cases

- Empty sentences after marking cells
- Sentences where all cells become known
- Board boundaries when calculating neighbors
- No safe moves available (must guess)
- All cells explored or identified

- Direct logic without unnecessary abstractions
- Use built-in Python set operations
