# Natural Language Parser Implementation Plan

## Overview
Implement a context-free grammar (CFG) parser for English sentences that can parse all 10 test sentences and extract noun phrase chunks.

## Test Sentences Analysis
1. `Holmes sat.` - Simple subject-verb
2. `Holmes lit a pipe.` - Subject-verb-object with determiner
3. `We arrived the day before Thursday.` - Complex noun phrase with prepositional phrase
4. `Holmes sat in the red armchair and he chuckled.` - Compound sentence with adjectives and preposition
5. `My companion smiled an enigmatical smile.` - Determiner + noun subject, adjective in object
6. `Holmes chuckled to himself.` - Prepositional phrase with reflexive pronoun
7. `She never said a word until we were at the door here.` - Adverb, conjunction, complex prepositional phrases
8. `Holmes sat down and lit his pipe.` - Compound verb phrase with adverb
9. `I had a country walk on Thursday and came home in a dreadful mess.` - Multiple prepositional phrases, compound verbs
10. `I had a little moist red paint in the palm of my hand.` - Multiple adjectives, nested prepositional phrases

## Required Grammar Patterns
From analyzing the sentences, we need to handle:
- Simple sentences: S -> NP VP
- Noun phrases with determiners: NP -> Det N | N
- Noun phrases with adjectives: NP -> Det Adj* N | Adj* N
- Verb phrases: VP -> V | V NP | V PP | V Adv
- Prepositional phrases: PP -> P NP
- Compound sentences: S -> S Conj S
- Compound verb phrases: VP -> VP Conj VP
- Nested structures: NP with PP modifiers, multiple adjectives

## Implementation Tasks

### Task 1: Implement `preprocess` function
**File**: `parser.py:58-65`

**Requirements**:
- Use `nltk.word_tokenize()` to tokenize the sentence
- Convert all words to lowercase
- Filter out words that don't contain at least one alphabetic character
- Return list of lowercased words

**Implementation approach**:
```python
def preprocess(sentence):
    tokens = nltk.word_tokenize(sentence)
    return [word.lower() for word in tokens if any(c.isalpha() for c in word)]
```

### Task 2: Design and implement CFG rules in `NONTERMINALS`
**File**: `parser.py:17-19`

**Core grammar rules needed**:

1. **Sentence structures**:
   - `S -> NP VP` - Basic sentence
   - `S -> S Conj S` - Compound sentences

2. **Noun Phrases**:
   - `NP -> N` - Simple noun
   - `NP -> Det N` - Determiner + noun
   - `NP -> Det AP N` - Determiner + adjectives + noun
   - `NP -> AP N` - Adjectives + noun
   - `NP -> NP PP` - Noun phrase with prepositional modifier

3. **Adjective Phrases**:
   - `AP -> Adj` - Single adjective
   - `AP -> Adj AP` - Multiple adjectives

4. **Verb Phrases**:
   - `VP -> V` - Intransitive verb
   - `VP -> V NP` - Transitive verb with object
   - `VP -> V PP` - Verb with prepositional phrase
   - `VP -> V NP PP` - Verb with object and prepositional phrase
   - `VP -> Adv V` - Adverb before verb
   - `VP -> V Adv` - Adverb after verb
   - `VP -> VP Conj VP` - Compound verb phrases

5. **Prepositional Phrases**:
   - `PP -> P NP` - Preposition + noun phrase

**Design considerations**:
- Avoid over-generation (e.g., "the the armchair")
- Avoid under-generation (must parse all 10 sentences)
- Keep rules general but not overly permissive
- Allow for recursive structures (NP -> NP PP for nested phrases)

### Task 3: Implement `np_chunk` function
**File**: `parser.py:68-75`

**Requirements**:
- Accept an `nltk.tree` object with label "S"
- Return list of `nltk.tree` objects with label "NP"
- Only return "noun phrase chunks" - NP subtrees that don't contain other NPs

**Implementation approach**:
1. Recursively traverse the tree
2. When finding a node with label "NP", check if it contains any NP children
3. If no NP children exist, it's a chunk - add to results
4. If NP children exist, don't add this NP (continue recursing into children)

**Algorithm**:
```python
def np_chunk(tree):
    chunks = []
    for subtree in tree.subtrees():
        if subtree.label() == "NP":
            # Check if this NP contains other NPs
            has_np_child = any(child.label() == "NP" for child in subtree.subtrees() if child != subtree)
            if not has_np_child:
                chunks.append(subtree)
    return chunks
```
